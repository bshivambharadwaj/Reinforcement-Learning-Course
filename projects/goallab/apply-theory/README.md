# Apply Theory with GoalLab

**Fourteen focused notebooks turn course concepts into working GoalLab components.**

Use this track to understand one method at a time: define an MDP, estimate values, train a controller, learn preferences, or explore search. The deliberately small two-source environment makes algorithm behavior easier to inspect.

**[Choose a notebook in the stage map →](../STAGES.md)**

Each notebook links back to the corresponding [course lesson](../../../notebooks/) and includes a worked experiment and a constraint-changing exercise. Notebooks run independently; they do not depend on hidden state from previous kernels.

When you are ready to assemble and evaluate the richer six-source investigation system, continue to **[Build GoalLab](../build-goallab/README.md)**. Its five project labs cover case generation, training, verification, evaluation, and the visual demo.
